# A research paper on root finding in finite fields

This work was presented as a poster at [ISSAC
2015](https://www.issac-conference.org/2015/), an abstract appeared in
the [ACM Communications in Computer Algebra, Vol. 49, No. 3, Issue
193](https://doi.org/10.1145/2850449.2850457).

An MIT-licensed version of the Python software is available from the
[software](../software) branch.
